# Rafa Pizza — Slider Lab

Prototype isolé du carrousel de pointes de pizza.

- Dépôt séparé du site public `Calendrier-Rafa`.
- Aucun fichier du site public n'est modifié.
- Navigation par clic, flèches, clavier, molette et swipe tactile.
- Objectif: valider le mouvement et l'expérience avant intégration éventuelle à rafapizza.ca.
